# Little Quiz Club

A small, free quiz website that we're building one step at a time.

## Project files

- `index.html` holds the page content.
- `styles.css` controls how the page looks.
- `script.js` contains the quiz questions and how the quiz works.

Keeping these jobs in separate files makes it easier to find and change things.

## Run the site

You don't need to install anything. Open `index.html` in a web browser to play
the quiz on your computer.

## Change a quiz question

1. Open `script.js` in a text editor.
2. Find the `questions` list near the top.
3. Each question has its question text, four answers, a `correct` number, and a
   fun fact. The answer numbers start at zero: `0` is the first answer, `1` the
   second, `2` the third, and `3` the fourth.
4. Save the file, then refresh the page in your browser.

## Free GitHub Pages hosting

This project is a static website, which GitHub Pages can host for free:

1. Open the repository on GitHub.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. After GitHub finishes publishing, the Pages settings will show the website
   address.

After you push future changes to `main`, GitHub Pages will publish them.
